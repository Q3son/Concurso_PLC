# Proyecto CODESYS

Guarda aquí el proyecto completo: `SmartFactory.project` (y opcionalmente una exportación
`SmartFactory.xml` con *Proyecto > Exportar PLCopenXML*).

El código fuente legible de cada POU está en las carpetas `01_DUT` a `05_PRG`, para que
el jurado pueda revisarlo directamente en GitHub sin abrir CODESYS.
